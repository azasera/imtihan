# Optional style profiles

Read this file only when the approved design direction or user explicitly names
a compatible profile. A profile refines execution; it never replaces product
colors, content, accessibility, or interaction requirements. Select at most one
primary profile for a surface.

## Minimalist editorial

- Let typography, rhythm, and negative space carry the hierarchy.
- Prefer flat grouping and quiet separators over nested cards and heavy shadow.
- Use restrained motion and a small number of meaningful images.
- Avoid mistaking absence of detail for finished minimalism.

## Industrial brutalist

- Use rigid grids, visible structure, assertive type scale, and utilitarian
  contrast.
- Keep controls legible and conventional even when the composition is raw.
- Use degradation, registration marks, or severe geometry sparingly; they must
  not obscure content or state.

## High-end dimensional

- Use depth, material, overlap, and generous spacing only where the design
  direction calls for them.
- Establish a small elevation system instead of applying nested bezels to every
  component.
- Remove overlap on narrow screens when it harms reading order or touch targets.

## Apple-inspired interaction

- Prioritize immediate feedback, direct manipulation, spatial continuity, and
  interruptible gesture motion.
- Use translucent materials only when content genuinely moves beneath them and
  contrast remains sufficient.
- Prefer restrained springs for touch-driven interactions; do not imitate
  platform chrome where normal web conventions are clearer.
